Sitefinity Preview Helper – Settings

Sites

prefix is the path used on the authoring server (empty for the main site). titleSuffixes are matched against the end of the Preview page's <title> (e.g. "Book Recommendations | Scottsdale Public Library"). If no suffix matches, the extension checks which authoring URL exists. siteId is the Sitefinity site ID, passed as ?sf_site= when opening the page editor.

Content types

Production pages ending in /details/<slug> are looked up through the site's public /api/default/<entitySet> service by UrlName. If a match is found, Edit opens /Sitefinity/adminapp/content/<adminType>/<id>/edit?sf_provider=<provider>; otherwise it edits the hosting page. The provider comes from the item itself; the provider setting is only a fallback. sites lists the site ids each type applies to (empty = all).
